# Northstar Heating & Home — Launch Site

A fictional portfolio concept demonstrating the $2,500 Launch package for a Michigan home-service contractor.

## Included
- 10-page responsive static site
- Home, Heating, Cooling, Indoor Air, Maintenance, Replacement, About, Reviews, Service Areas, Request Service
- Mobile sticky call/book/emergency actions
- Accessible navigation and forms
- Basic HVACBusiness JSON-LD
- Demo ZIP checker
- Demo request form behavior
- Reduced-motion support
- Local SVG illustrations (no external dependencies)

## Intentionally NOT included in Launch
- Live CRM or booking integration
- After-hours phone routing
- Missed-call SMS
- Dynamic review sync
- Financing application/widget
- Lead scoring/routing
- Territory-aware scheduling
- Custom API work

Those belong to Growth / Operations / Custom scope.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Portfolio disclaimer
Northstar Heating & Home is fictional. The 555 phone number, team, reviews, membership pricing, business claims and coverage are demonstration content.
