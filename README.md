# Northstar Heating & Home

Northstar Heating & Home is a fictional Metro Detroit HVAC website created as a portfolio demonstration of a modern, conversion-focused home-services website.

## Highlights
- Responsive multi-page experience
- Heating, cooling, indoor-air, maintenance and replacement journeys
- Repair-or-replace interactive guidance tool
- Context-aware request-service form
- Service-area ZIP checker
- Comfort Club and financing paths
- Mobile call, booking and urgent-help actions
- Accessible navigation and form patterns
- Portfolio-safe noindex metadata

## Portfolio disclosure
Northstar Heating & Home is fictional. Company details, team members, reviews, pricing, credentials, phone numbers and service information are illustrative portfolio content and are not representations of a real HVAC business.
