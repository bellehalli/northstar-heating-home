# Northstar Public Build Notes

This repository contains a fictional HVAC portfolio website intended to demonstrate front-end design, conversion architecture and interactive customer journeys.

## Functional demonstrations
- Problem-first homepage routing
- Service-specific calls to action
- Repair-or-replace guidance quiz
- Query-string form prefilling
- Core and extended ZIP coverage responses
- Responsive mobile navigation and quick actions
- Accessibility-conscious forms, focus states and reduced-motion behavior

## Production note
A real business deployment would replace all fictional business information with client-approved details and connect forms, scheduling, phone routing, analytics, reviews and other integrations to the client's real systems.

No personal information entered into this portfolio demonstration is transmitted or stored.
